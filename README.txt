あそびランド 更新版（試用版）

ZIP内の8ファイル＋extras.jsをGitHub Pagesのリポジトリ直下へアップロードし、既存ファイルを置き換えてください。
更新後はiPadのPWAを完全終了して再起動してください。古い画面ならSafariのサイトデータ／キャッシュ更新が必要な場合があります。

既存パズル画像は元のIndexedDB（asobi-land-v1）に保存されたままです。ぬりえ・なぞりがき登録画像は別のIndexedDB（asobi-land-extra-v1）を使用します。端末やブラウザを変更すると引き継がれません。

注意：
・iPad Safari/PWAでApple Pencilの筆圧取得、マイク音声認識、写真への保存を実機検証してください。
・写真保存は共有シートから「画像を保存」を選ぶ方式。共有非対応ならファイルダウンロードです。
・バケツ塗りは簡易的な隙間補正（2px膨張）で、複雑な線画は漏れる可能性があります。
・なぞりがきの合格判定は厳密な線追跡ではなく描画距離による簡易フィードバックです。
・ひらがなプリセットは一部文字から開始しています。
・クーピー24色は近似色・仮の色名です。実物の正確な色構成と照合が必要です。
・公開リポジトリには著作権キャラクターの画像を含めていません。

[v8] ぬりえ描画を増分更新して遅延を軽減。取り込み時の強制二値化を廃止しアンチエイリアス保持。なぞり書き成功時の「わあ」音声なし。色名の日本語・英語表示。筆サイズ4段階（10/16/24/36）。
※以前のバージョンで登録済みの下絵は二値化された状態で保存されているため、滑らかな輪郭にしたい場合は元画像から再登録が必要です。
